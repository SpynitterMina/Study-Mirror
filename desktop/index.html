Not connecting?
  1. Phone and laptop must be on the same Wi-Fi (not a guest network).
  2. If Windows asked about network access, choose Private networks and Allow. Missed it?
  3. Test from the phone's browser: http://... should say ok.
  4. Still no luck? Some routers block devices from talking to each other. Turn on the phone's hotspot, join it from the laptop and press New code.
QR pairing needs the Study Mirror desktop app, because it runs the small listener the phone talks to. In a browser, open Config → Phone Link and type the phone address and pairing code from the app.
